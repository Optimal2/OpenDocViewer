## Changes Since v2.9.0

- **Search in the help dialog.** The manual dialog has a search field in its header, visible while the manual is shown. Typing at least two characters highlights every match in the rendered manual after a short delay and shows "N of M"; Enter / Shift+Enter and the previous/next buttons move between matches, the current match is scrolled into view and collapsed `<details>` sections open around it, and Escape clears the search without closing the dialog. Matching is case-insensitive in the UI language (Swedish å/ä/ö included). The field has a label, an `aria-live` counter and a visible focus ring, and the placeholder follows the UI language (Swedish and English).
- **Sanitization unchanged.** The manual HTML is still cleaned with the same DOMPurify configuration. The search is part of the dialog's own code; it highlights with the CSS Custom Highlight API where available and otherwise with temporary `<mark>` elements that are removed again. No dependencies were added.
- **OMP component.** `opendocviewer-web` is versioned in `omp-components.json` alongside the release.

## Upgrade Guidance

Upgrade v2.9.0 deployments to v2.10.0. No site-configuration changes are required, and the build and Node.js requirements are unchanged from v2.9.0. Site manuals in `help/site/` and the bundled manual in `help/default/` both get the search; nothing needs to be added to the manual files.
